# v0.1.21 Beta

这是一个安全补丁版本，修复 Bridge Sidecar 将本机控制凭据写入持久日志的问题。

## 安全修复

- Sidecar 不再向 stdout 或 stderr 输出完整配对链接、Pairing Token 或 Local Control Token。
- 启动输出仍保留监听地址、PWA 资产就绪状态和 Codex 连接状态，供本机支持排障使用，同时不记录完整本机路径。
- 安装此版本后首次启动以及之后每次启动 Sidecar 时，桌面壳都会在新进程写日志前截断旧的 Sidecar stdout/stderr 日志。清理过程不会复制、打印或生成包含旧凭据的迁移文件。
- 每次启动 Sidecar 都会生成新的 Local Control Token；旧进程内尚未使用的配对链接也会随进程退出而失效。已经配对且未被撤销的设备不受影响。

建议所有 Beta 用户升级到此版本，并在升级后至少启动一次 Bridge Service，以完成旧日志清理和控制凭据轮换。
