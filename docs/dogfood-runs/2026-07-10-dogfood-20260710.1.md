## Manual Dogfood Scope

Run these on at least one daily-driver Mac and one phone before sharing the build with more colleagues.

### Install And Startup

- [ ] Launch `/Applications/Codex Mobile Bridge.app`.
- [ ] Click `检测/启动`.
- [ ] Confirm ChatGPT/Codex Desktop is detected or opened.
- [ ] Click `Bridge Service / 启动`.
- [ ] Confirm the bridge status is `ready` or has a clear degraded reason.

### LAN Pairing

- [ ] Click `手机配对 / 生成新链接`.
- [ ] Open the generated LAN pairing link on the phone.
- [ ] Confirm the phone does not show demo sessions when unpaired.
- [ ] Confirm pairing succeeds and refresh preserves the device session.
- [ ] Reopen the bridge root URL on the same phone browser and confirm it remains paired.

### Session Read And Send

- [ ] Select a real ChatGPT/Codex task on the phone.
- [ ] Confirm messages render oldest-to-newest, with newest at the bottom.
- [ ] Confirm user messages and Codex replies are visually distinct.
- [ ] Send a text reply from the phone.
- [ ] Confirm the desktop task receives the message.
- [ ] Confirm the phone receives the next Codex reply after polling.

### Lock Screen Recovery

- [ ] While a task is active, lock the phone for at least 30 seconds.
- [ ] Unlock and return to the PWA.
- [ ] Confirm the status recovers without requiring a fresh pairing link.
- [ ] Confirm new session events continue syncing.

### Approval

- [ ] Trigger a real ChatGPT/Codex approval request, or use the debug approval endpoint for smoke.
- [ ] Confirm `Pending approvals` appears only while an approval is pending.
- [ ] Approve from the phone and confirm the desktop task continues.
- [ ] Trigger another approval, reject from the phone, and confirm the desktop task receives rejection.
- [ ] Confirm resolved approvals disappear from the top area.

### Quick Tunnel Beta

- [ ] Click `远程链接 Beta / 开启`.
- [ ] Open the generated remote pairing link on mobile network or another network.
- [ ] Confirm the remote root URL can be reused after pairing on the same phone browser.
- [ ] Rotate the tunnel and confirm the old link is no longer treated as current.
- [ ] Stop the tunnel and confirm public access fails or shows a clear connection error.

### Device Revocation And Diagnostics

- [ ] Confirm the desktop app lists the paired phone.
- [ ] Revoke the phone.
- [ ] Confirm the phone can no longer read sessions or send messages.
- [ ] Copy diagnostics and manually check there are no tokens, API keys, or full local paths.

## Notes

- Quick Tunnel remains Beta and temporary; do not present `trycloudflare.com` links as stable remote access.
- Full pairing URLs with `pairingToken=...` are one-time entry points.
- A root bridge URL is reusable only on a phone/browser that already has a valid saved device session.
