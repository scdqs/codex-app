## Affected Pages/Routes

- 手机 PWA 新建会话 sheet：加载、默认选择、切换和错误恢复工作目录。
- `GET /api/workspaces`：返回当前 Desktop 会话派生出的安全目录。
- `POST /api/sessions`：携带 `cwd`，在创建前完成新鲜校验。

## Key Interactions to Verify

- 当前会话有合法 `cwd` 时默认选中该目录。
- 单一合法目录自动选中；多目录无上下文时要求用户选择。
- 创建成功后选中新会话，Desktop 开始回复且目录正确。
- 401/403 时刷新设备 session 一次并重试；其他错误不触发刷新。
- 提交失败时保留文本、图片附件和目录选择。
- 快速重复点击只发出一次创建请求。

## Edge Cases

- 过滤 `/`、相对路径、普通文件、不存在目录和重复目录。
- 工作目录列表为空、加载失败、Desktop adapter 不可用。
- 列表展示后目录被删除或不再出现在最新 `thread/list`。
- 请求被篡改为未授权绝对路径。
- 新结构化错误与旧纯文本错误响应都不会导致 PWA 崩溃。
- Workspace 400 不显示配对链接过期；配对 400 仍显示正确配对错误。

## Critical Paths

- 自动测试：Rust policy/API/adapter + TypeScript protocol/API/React 全部通过。
- 真实 E2E：手机选择真实项目 -> Bridge 校验 -> Desktop 创建 -> 首条回复 -> cwd 一致。
- 安全 E2E：篡改 cwd -> Bridge 拒绝 -> Desktop 不创建线程。
- 恢复 E2E：目录失效 -> 草稿保留 -> 刷新目录 -> 重选后成功。
- 网络 E2E：LAN 与 Cloudflare Quick Tunnel 各完成一次创建。
